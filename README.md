# Swing-Calculator

A basic calculator application built with Java Swing.

## Features

- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), division (/)
- Decimal number support
- Clear (C) button to reset the calculator
- Delete (Del) button to remove the last digit
- User-friendly GUI with a grid layout

## Requirements

- Java Development Kit (JDK) 8 or higher

## How to Compile and Run

### Option 1: Using the run script (Linux/Mac)

```bash
./run.sh
```

### Option 2: Manual compilation and execution

Compile:
```bash
javac src/calculator/Calculator.java
```

Run:
```bash
java -cp src calculator.Calculator
```

## Usage

1. Click number buttons (0-9) to enter numbers
2. Click an operation button (+, -, *, /) to select an operation
3. Enter the second number
4. Click the equals (=) button to see the result
5. Use the C button to clear all
6. Use the Del button to delete the last digit
7. Use the decimal (.) button to enter decimal numbers
